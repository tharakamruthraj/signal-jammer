Signal Jammer (NRF Box)
Overview
This project is a portable wireless tool built using an ESP32 and NRF24L01 module. It serves as an educational platform to explore radio frequency (RF) behavior in the 2.4 GHz ISM band.

Features
Signal Jamming: Demonstrates disruption of Bluetooth and 2.4 GHz Wi-Fi signals within a 5–10 meter range.

RF Scanning: Real-time detection of nearby SSID and MAC addresses.

Bluetooth Spoofing: Simulates pairing notifications (e.g., Apple AirPods) to test device vulnerabilities.

Custom PCB: Integrated design for stability and portability.

Hardware Components
ESP32 Microcontroller

NRF24L01 RF Module

OLED Display Interface

3.7V Lithium-ion Battery
